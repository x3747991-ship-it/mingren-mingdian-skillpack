# 名人命典（celebrity-bazi）

> 输入你的八字四柱，自动检索典籍与全网信息，找出「四柱前三柱（年柱 / 月柱 / 日柱）」与你完全相同的名人，并据《五行精纪》禄命法八科为你的八字分断。

## 一句话说明

「名人命典」是一个**八字 / 四柱检索类 AI 技能包**。你输入八字四柱（或公历出生日期），它会：

1. **跨甲子反推**这组三柱在历史跨度内的全部出生日期；
2. **联网检索 + Wikidata 核实**每个日期 / 日柱对应的名人；
3. **离线命例库**（约 2032 条四柱级命例）不联网秒回补充；
4. 只返回与你**同四柱 / 同三柱**的「同命人」及其人生经历；
5. 据《五行精纪注释》**禄命法八科**为你的八字做完整分断。

最终呈现：**这个八字有哪些同命人、他们分别是谁、有什么样的人生经历，然后输出完整的八字分析结果。**

## 核心能力

| 能力 | 说明 |
|---|---|
| 🌐 跨甲子全覆盖 | 同一组三柱每 60 年（一个甲子）循环出现，本技能列出它对应的**全部**历史日期并逐档查人，不漏前几个甲子 |
| 🧭 多源交叉核实 | 百度百科 + 维基百科 + Wikidata（P569 日级出生日期）三重比对，剔除讹误 |
| 📚 离线命例库 | 内置约 2032 条四柱级命例（343 位具名名人 + 古籍命例 + 赛事命例），本地离线秒回 |
| 🔬 禄命法八科分断 | 纳音体用 / 干支合化 / 三元胎元 / 吉神贵格 / 凶神贫贱 / 六亲性情 / 健康寿夭 / 大运岁运，规则均带卷·块号出处 |

## 核心事实

四柱的**前三柱（年 / 月 / 日柱）完全相同**与「出生日期」的关系：

- **同一甲子周期内**：三柱相同 ⟺ 同年同月同日出生。
- **跨甲子**：同一组三柱每 60 年循环出现，但会落到**不同日历日**（受日柱 60 天循环与节气百年漂移影响），中间可能「断档」。

因此「查同三柱名人」= 先用 `bazi.py reverse` 得到这组三柱在给定时间跨度内的**全部**候选日期，再对每个日期逐一检索出生者。

## 依赖与安装

- Python 3
- `lunar_python`（纯 Python）：`python -m pip install lunar_python --no-build-isolation`
- 离线检索脚本（`scripts/查同八字.py`）内置 `_vendor/lunar_python` 离线排盘，`--bazi` 查询无需联网。

---

## 使用方式

把本目录作为 TRAE 技能安装（`SKILL.md` 为入口），在对话中直接输入八字或出生日期即可，例如：

```
甲子 乙亥 庚戌 癸未 男
```

或：

```
1984-11-12
```

技能会自动：

1. 解析前三柱 → 2. 跨甲子反推全部候选日期 → 3. 本地命例库离线检索 + 联网多源检索并核实 → 4. 汇总同四柱 / 同三柱同命人 → 5. 禄命法八科分断八字。

---

## 数据来源

- **Wikidata**：结构化出生日期（P569，日级 precision）交叉核实。
- **百度百科 / 维基百科**：名人出生日期词条核对。
- **本地四柱命例库**：从《五行精纪》等古籍及赛事命例整理，约 2032 条。
